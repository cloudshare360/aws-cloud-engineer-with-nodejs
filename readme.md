# AWS Cloud Engineer Full-Stack Learning Roadmap

> **New here? Start here and follow this file top to bottom — no human help needed.**
>
> 1. **Read this hub fully once** (~5 min) to understand where everything lives.
> 2. **Do the tasks in order:** open the [todo-task master index](todo-task/README.md) (lists all 11 tasks with links), start at [task-01](todo-task/task-01-setup-install-scoop.md), and finish each task's ✅ checklist before opening the next file. Each file links to its successor, so you never have to guess what comes next.
> 3. **Study JavaScript daily** in [programiz-learning/](programiz-learning/) following [task-08](todo-task/task-08-js-learning-plan-schedule.md) (the 11-week schedule) and [task-10](todo-task/task-10-daily-execution-google-sheet.md) (the daily routine + Google Sheet logging).
> 4. **Use the repo map below** whenever you're lost: it shows every part of this repo and exactly which file to open next.

This roadmap is organized for an associate who wants to become an AWS Cloud Engineer with strong full-stack development skills using Node.js, React.js, Angular, and cloud deployment practices.

## Anti-Duplication Rules (how this repo stays consistent)

1. **One canonical home per fact.** The 59 Programiz topics (name → URL → folder → Estimated Hours) live **only** in [programiz-learning/README.md](programiz-learning/README.md). Everywhere else links to it.
2. **One canonical home per resource.** Each video/guide appears in the section that uses it ([read_resources.md](docs/readme/read_resources.md) is the index, not a second copy).
3. **Content vs progress.** Repo = content (`index.md` notes); Google Sheet = progress (Actual dates). Never mix.
4. **Order vs how.** `todo-task/` = order; `How-To-Do/` = how. Tasks link to guides; guides never define order.
