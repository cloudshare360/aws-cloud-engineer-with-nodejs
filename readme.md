# JavaScript Learning Path

These tutorials will provide you with a solid foundation in JavaScript and prepare you for the next step in your career.

## Day 1: Setup and Version Control

From day one, the learner should understand the tools and workflow used in real development environments.

### Required setup

- Install Node.js
- Install Git
- Install VS Code
- Create a GitHub account
- Create a GitHub repository for learning progress
- Learn Git basics: commit, branch, pull, push, merge
- Understand GitHub Codespaces and how cloud-based development environments work

### Git learning resource

- [Git Tutorial for Beginners: Learn Git in 1 Hour](https://www.youtube.com/watch?v=2ReR1YJrNOM)

### Daily workflow

- Commit progress to the Git repository every day
- Save code and notes in a structured learning repository
- Create a Google Sheet to track daily progress
- Maintain a simple Kanban board for learning tasks
- Review progress regularly and update backlog/status

## Project Management and Agile Concepts

Because the process matters, the learner should understand the principles behind modern development workflows.

- Kanban basics
- Scrum basics
- Daily standups and task tracking
- Sprint planning and progress review
- Backlog management
- Work-in-progress limits
- Visual tracking of tasks and learning milestones

## Daily Practice Requirement

The learner should maintain:

- a local or GitHub-hosted Git repository
- a daily commit habit
- a Google Sheet progress tracker
- a simple Kanban-style task board
- notes for concepts learned, tasks completed, and blockers

This habit builds both technical and process discipline from the beginning.
