# JavaScript Learning Roadmap

This skill provides the structured JavaScript learning path defined in this repository's main roadmap (`readme.md`, sections 3 and 9).

## Learning Progression

1. **JavaScript Fundamentals**
   - Variables and constants
   - Data types, operators, and type conversion
   - Control flow (if/else, loops, switch)
   - Functions and variable scope
   - Closures

2. **JavaScript Objects and Arrays**
   - Object creation and methods
   - Prototypes and constructor functions
   - Arrays and array methods
   - Strings, numbers, and symbols

3. **ES6 and Modern JavaScript**
   - Arrow functions
   - Template literals
   - Destructuring assignment
   - Spread and rest operators
   - let / const vs var
   - Default parameters

4. **OOP and Design Patterns**
   - Classes and inheritance
   - Modules (import/export)
   - Error handling (try/catch/throw)

5. **Asynchronous JavaScript**
   - Callbacks
   - Promises
   - async/await
   - setTimeout and setInterval

6. **Miscellaneous**
   - this keyword
   - JSON
   - Date and time
   - Regex
   - Iterators and generators

## Verification

After completing a topic, verify understanding by:
1. Explaining the concept in your own words.
2. Writing a small code example without reference.
3. Testing edge cases.
4. Committing the code with a descriptive message.
