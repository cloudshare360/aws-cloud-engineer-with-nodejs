# read_career_outcome — Section 1: Career Outcome

**Where you are:** [readme hub](../../readme.md) → Section 1 of 12 → next: [read_setup_environment](read_setup_environment.md)

By the end of this roadmap, the learner should be able to:

- build and deploy REST APIs with Node.js
- build frontend applications with React.js / Next.js and Angular
- understand full-stack application architecture
- deploy applications to AWS
- use GitHub for code management and collaboration
- track work using Kanban and Scrum practices

## The end-to-end skill set this roadmap builds

- JavaScript fundamentals
- backend development with Node.js and Express
- frontend development with React.js / Next.js and Angular
- version control and development workflow with Git and GitHub
- AWS cloud services and deployment patterns
- project discipline using Kanban and Scrum

## How this roadmap is meant to be used

This repo is a **self-guided** learning workspace. You never need a human to tell you what to do next:

1. **Order** — [todo-task/](../../todo-task/) files run in strict numbered order; each file's ✅ checklist gates the next.
2. **How** — [How-To-Do/](../../How-To-Do/) guides explain each setup step in depth (cheatsheets, screenshots, CLI + VS Code variants).
3. **Content** — [programiz-learning/](../../programiz-learning/) holds the 59 JavaScript topics offline.
4. **Progress** — the Google Sheet is the single source of truth for what you planned vs what you actually did (see [read_javascript](read_javascript.md)).
